#  HTTP Server 
**Name:** خالد محمد احمد السيد المصري
## What this code does
This project creates a simple HTTP server using Node.js. It has three GET requests and one POST request.
## How it works
1. The home page shows a welcome message.
2. The `/users` request returns a list of users.
3. The `/products` request returns a list of products.
4. The `/add-data` request receives data and returns that it was received and stored.
5. If the page is not found, it returns an error message.
