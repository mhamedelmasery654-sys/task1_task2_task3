## What this code does
This project creates a simple notes app using Node.js and Express. It can add, show, update, edit, and delete notes.

## How it works
1. I used Express to create the server and the notes endpoints.
2. The notes are saved in the `notes.json` file.
3. The `GET /notes` endpoint shows all notes.
4. The `POST /notes` endpoint adds a new note.
5. The `PUT` and `PATCH` endpoints update a note.
6. The `DELETE` endpoint removes a note.
7. If a note is not found, the server returns a simple error message.
